A website to show major stations of switzerland!


# Legend 
Size = how many trains depart from that station in the next 30 minutes
Color = how punctual its been recently (green = on time, red = 5+ min late)
Pulse speed = how busy the station is!!

# stations tracked
Zürich HB, Genève, Bern, Basel SBB, Lausanne, Luzern

# Open source data 
All data is coming from transport.opendata.ch its a public API over the Swiss public transport network. Im using the stationboard endpoint 
to pull live data of train departures.
